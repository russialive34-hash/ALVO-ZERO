# QUEDA LIVRE

Battle royale online no navegador e no celular (20 jogadores, completa com bots).

- Espera no **trem voador** (Expresso Céu), que atravessa a ilha: aperte PULAR.
- Queda livre na **prancha voadora** e paraquedas.
- Loot em baús: armas (pistola, SMG, fuzis, escopeta, sniper), munição, colete, capacete, kit médico, **parede de gelo**, miras 2x/4x/8x e moedas.
- **Drop de suprimentos** cai do céu com loot raro.
- Pule cercas e janelas, zona segura que fecha, bots com IA.

## Rodar
```
npm install
npm start
```
Render: Language **Node**, Build `npm install`, Start `npm start`.

APK (Termux): `bash apk-termux.sh https://SEU-SITE.onrender.com`
